# Release checklist

Подписывается ответственным лицом перед тем, как считать релиз готовым. Checklist не заменяет
CI — он подтверждает, что развёрнутая система проверена сквозным образом, без реальных данных
клиентов.

## Post-deploy smoke

- [ ] `./scripts/post-deploy-smoke.sh <BASE_URL>` прошёл: health `ok`, root отвечает `200`.
- [ ] `pnpm test:integration` прошёл против целевой базы.
- [ ] Миграции применены, в логе `deploy-*.yml` нет ошибок, dry-run совпадает с ожидаемым.

## Безопасность и данные

- [ ] RLS включён на всех business-таблицах (access matrix, тикет 60, проходит).
- [ ] Секреты не видны в браузере (`NEXT_PUBLIC_*` содержит только публичные ключи).
- [ ] Rate limiting и consent-гейты работают (тикеты 61, 13).
- [ ] AI-вывод не обходит review/evidence rules (тикеты 32–37, 59).

## Отказоустойчивость

- [ ] Restore drill пройден и подписан (см. [backup-restore.md](./backup-restore.md)).
- [ ] Откат приложения проверен (redeploy предыдущего деплоя Vercel).
- [ ] Логирование и алерты включены (тикет 62).
